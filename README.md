
# FeedBoard – Customer Feedback & Feature Voting Portal

**Listen. Prioritize. Build Better.**

FeedBoard is a modern, responsive customer feedback platform that helps businesses collect feature requests, prioritize product improvements, and understand customer needs through community voting.

## 🚀 Features

- Responsive SaaS landing page.
- Hero section with interactive dashboard preview.
- Features, How It Works, Pricing, and Contact sections.
- Sign Up and Sign In with form validation.
- Demo authentication using browser storage.
- Protected dashboard routes.
- Dashboard summary cards and profile page.
- Reusable React components.
- Toast notifications for success and error messages.
- Responsive navigation for mobile, tablet, and desktop.
- Smooth animations and transitions.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| React.js | Frontend development |
| Vite | Development and build tool |
| Tailwind CSS v4 | Styling and responsive design |
| JavaScript (ES6+) | Application logic |
| React Router DOM | Client-side navigation |
| Motion | UI animations |
| Lucide React | Icons |
| LocalStorage / SessionStorage | Demo authentication |

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd feedboard
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal, usually:

```text
http://localhost:5173
```

## 🎨 Design Choices and Challenges

- Chose a teal and mint color palette to create a fresh, professional SaaS appearance.
- Used clean typography, rounded cards, and subtle shadows for a consistent visual experience.
- Built reusable React components to improve code organization and maintainability.
- Used Tailwind CSS responsive breakpoints to support mobile, tablet, and desktop layouts.
- Added Motion animations to make the interface more engaging.
- Implemented client-side form validation and toast notifications for better user feedback.
- Improved tablet navigation and mobile layouts to prevent overlapping and clipped content.
- Used React Router for page navigation and browser storage for frontend-only demo authentication.

## 🔐 Demo Authentication

FeedBoard uses LocalStorage and SessionStorage for demonstration purposes.

- Register an account through the Sign Up page.
- Sign in using the registered account.
- Access the protected dashboard.
- View your profile and log out.

**Note:** This is a frontend assignment. Authentication is simulated using browser storage and is not production-secure. No backend or database is connected.
